BUDDY - REPRODUCTION OF THE CURRENT LOCAL CANDIDATE

Use external Open Watcom 1.9 and Python 3 on a modern developer host.
No tools, OS images or ROMs are bundled. All output directories must be NEW.
Run commands from the repository root; supply absolute tool/output paths.

WINDOWS (app-local player, clocks, private mapper, DOS broker)
python examples/BUDDY/WIN30/source/BUILD.PY --watcom C:\WATCOM --out C:\NEWBUILD
python examples/BUDDY/WIN30/PACK.PY --build C:\NEWBUILD --watcom C:\WATCOM --out C:\NEWPACK
WINPLAY.ZIP contains the verified runtime and fresh-only BUDSET installer.
WINSRC.ZIP is the corresponding standalone Windows source tree, including
the two current engine mirror assembly inputs and their license notices.
Unzip WINSRC.ZIP into a new directory; run the same source/BUILD.PY command
there. PACK.PY also emits SOURCE.ZIP and exact package SHA256/CRC metadata.
No emulator is launched by these builders. Win16 C uses -zW -0 -ms -os -s
-w3 (-zu for DLLs); WASM uses -0. DOS installer uses -bt=dos -0 -ms -os.
The current WINHOOK/TBRIDGE mirror is copied at build time, not replaced.
The canonical published SOUND/MIDI driver and its MSC6/MASM/LINK4 toolchain
are unchanged. Historical Windows BUILD.BAT batches are incomplete legacy
paths; use the complete BUILD.PY path above for this app-local candidate.
See WIN30/source/BUILD.TXT for contributor controls and scoped host checks.

DOS (updated portable player, 8086 small model)
python examples/BUDDY/DOS/HOST/BUILD.PY --watcom C:\WATCOM --out C:\NEWDOS
The DOS target uses Open Watcom C16 -0 -ms -os -s -w3 -ecc and WASM -0.
See DOS/README.TXT for host C89 checks, deterministic runtime packaging
with DOS/HOST/PACK.PY, resources and the 24-case native qualification.
No accepted four-voice score, cue, source video or beat map changes here.
The sparse speaker asset and all 128 speaker PIT periods match Windows.

MEDIA REGENERATION (developer host only)
python examples/BUDDY/WIN30/host/ARRANGE.PY
python examples/BUDDY/WIN30/host/SPEAKER.PY --out C:\NEWMUSIC
python examples/BUDDY/WIN30/host/CONVERT.PY YOUR.WEEZER.AVI NEW.WZV
python examples/BUDDY/WIN30/host/PLANAR.PY NEW.WZV NEW.WZP
CONVERT requires Pillow and FFmpeg/ffprobe. For larger DOS video add
--width 128 --height 96 --fps 8. Supply your own source video; consult
ATTRIB.TXT before redistribution. No media tools fetch from the network.
WZP rearranges all 966 tiny WZV frames losslessly, without a new quantizer.
WIN30/media/README.TXT records the approved WZV palette encoding provenance.
