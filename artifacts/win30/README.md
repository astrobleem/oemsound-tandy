# Windows 3.0 / 8088 PSG milestone

MILESTONE.ZIP is the validated pre-publication package snapshot, with complete source, build instructions, captured audio, screenshot, test reports and scoped audits. The current source is also under src/win30. README.TXT describes installation, rollback and limitations. MANIFEST.JSON describes paths inside the ZIP.

PSGPLAY.EXE and optional TCHIME.EXE work without replacing the stock driver. TSOUND.DRV is an experimental restricted legacy API implementation for cloned test installations only. No stock beep, noise, envelopes or SyncAllVoices support; abrupt owner termination is unqualified. Physical hardware listening remains unverified.

The repository README/license mismatch is preserved; this milestone makes no new licensing claim. No stock Windows, DDK or toolchain binaries are included in this package.
