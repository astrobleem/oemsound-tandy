# Windows sound downloads

Use [the current download guide](../../docs/DOWNLOADS.MD) to choose Setup,
Winamp, the music tools or Effects Lab. [Install from DOS](../../docs/INSTALL.MD).

The current packages in this folder are TWSETUP.EXE, TWXT2.ZIP, MML3AUTH.ZIP,
PITEXPR.ZIP and EFFECTS.ZIP. Their runtime/source bytes are retained with
matching validation records.

The older loose executables, README.TXT, component folders and MILESTONE.ZIP
are historical snapshots. Their original version and limits are preserved
in [the milestone notes](MILESTONE.MD); they are not the current install path.
