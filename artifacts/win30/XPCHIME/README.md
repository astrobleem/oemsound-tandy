# Optional XP-note PSG startup chime

XPCHIME.EXE is a separate 4,543-byte alternative to the original TCHIME.EXE. XPCHIME.WAV is a captured emulator preview, not a file played by the executable. MILESTONE.ZIP contains source, all native captures, startup observer evidence, host tests and scoped binary audit. README.TXT has reversible opt-in instructions and limitations. MANIFEST.JSON describes paths inside the ZIP.

The six melody notes follow the user-supplied score credited to Bill Brown, arranged by David Caldarella. Two low bass notes are raised an octave for the PSG range. No supplied score image or original Windows audio sample is included. This is a three-square-wave reduction, not a timbre-identical recording.

Windows 3.0 real mode / 8088 and known original Tandy PSG only. Run one PSG producer at a time. No SOUND.DRV replacement is needed. Physical hardware remains untested; cooperative Windows can delay timer delivery. Existing licensing notices and the repository README/LICENSE mismatch are preserved.
