# Demo projects

These native players and earlier projects show other uses of PC sound. For current driver
installation and music tools, use [the main guide](../README.md).

- **Buddy Holly tiny players:** actual DOS and Windows 3.0 frame-video playback,
  with PC-speaker or Tandy-compatible PSG sound.
  [Downloads](DOWNLOADS.MD#buddy-holly-tiny-video-players) and
  [installation and controls](../examples/BUDDY/README.TXT).
- **Buddy Holly / BUDCAP:** an offline video export with PSG music and timed
  captions. [Watch the demo](https://youtu.be/wzUQWxt3Eno), view the
  [authentic emulator preview](SHOTS/BUDCAP04.GIF), or read the
  [BUDCAP project guide](../examples/BUDDY/BUDCAP/README.md).
- **Call Me oscilloscope:** an offline visualization of a PSG and PC-speaker
  arrangement. [Watch the video](https://youtu.be/gpdcfCYBdpk).

These are separate projects, not extra playback features or media included
with the normal driver download. [Capture provenance](SHOTS/README.MD).
