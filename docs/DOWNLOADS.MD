# Current sound downloads

Choose the program you want. These are different tools, not a sequence of
software versions to install.

- **Winamp and its TSOUND driver:** [TWXT1.ZIP](https://github.com/astrobleem/oemsound-tandy/releases/download/tandy-winamp-xt1.20261024/TWXT1.ZIP) ·
  [Install](../experimental/WINAMP30/INSTALL.TXT).
- **Fiddle and Beats music authoring:** [MML3AUTH.ZIP](https://github.com/astrobleem/oemsound-tandy/releases/download/sound-exp-v0.1.0-pit.20261007/MML3AUTH.ZIP) ·
  [Install](../experimental/PITPUBLIC/INSTALL.TXT).
- **Mini Piano, JoyMIDI, MiniMIDI and expressive Beats:** [PITEXPR.ZIP](https://github.com/astrobleem/oemsound-tandy/releases/download/sound-exp-v0.1.0-pit.20261007/PITEXPR.ZIP) ·
  [Install](../experimental/PITPUBLIC/INSTALL.TXT).
- **DOS PSG sound test:** [PITDOS.ZIP](https://github.com/astrobleem/oemsound-tandy/releases/download/sound-exp-v0.1.0-pit.20261007/PITDOS.ZIP) ·
  [Run from DOS](../experimental/PITPUBLIC/INSTALL.TXT).

The Windows tools need an installed Windows 3.0 real-mode system on a
Tandy 1000 EX/HX with 640 KB. Each Windows packet includes its paired sound
driver. Winamp also includes the required video-memory helper.
