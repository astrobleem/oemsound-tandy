TANDY WINAMP - INSTALL AND PLAY

For Tandy 1000 EX/HX, DOS 3.0+, normal 640 KB and Windows 3.0 real mode.

INSTALL
Extract the TWXT2 folder from the ZIP on the DOS computer. Exit Windows and
run SETUP.EXE in that folder. Setup finds Windows, offers a choice if several
installations exist, and installs the player in C:\WINAMP.
It installs the shared SOUND.DRV, selects it in Windows, and supplies the
player DLLs, timer bridge and video-memory helper automatically. Existing
Windows XT sound clients use the same driver.

After Setup completes, start from plain DOS:
  C:\WINAMP\GO

No Windows driver copying, INI editing or separate helper download is needed.
The ZIP contains SETUP.EXE, the actual runtime files and corresponding
source. No separate executable or helper download is required.

PLAY
Choose Add... to select MID, VGM, VGZ, MOD, TND or SND files. The playlist holds
32 songs; scroll or use Home/End/Page Up/Page Down. Remove changes the list,
not the song file. Stop and close the player, then exit Windows normally.

Use MIDI: Default / MIDI: Chamber to choose a FauxBlaster instrument bank.
In a compact window the button says Default / Chamber. The choice is saved
automatically beside the player and reapplied when you reopen it or a song.
New melodic notes use the chosen bank; held notes keep their original shape.
VGM/VGZ register playback and percussion keep their original sound.

GO starts the guarded real-mode launcher. For HPXY and XRSYNC it reserves or
reuses the required video memory, loads the owned timer bridge, starts
Windows and the player, and removes that bridge after normal Windows exit.
Stock CGA uses the same command. The video reservation is reused until reboot.
Sound ownership prevents competing apps from changing one another's output;
stop the current producer before starting another.

REPAIR OR REMOVE
Run C:\WINAMP\SETUP in plain DOS for Launch, Repair or Uninstall Winamp.
Repair checks the current installation and restores its owned files. For a
missing or damaged cached file, run SETUP from the extracted download and choose Repair. Uninstall removes Winamp while keeping shared Windows sound
and Windows XT clients. Unrelated files and settings are preserved.

Setup and GO report a specific error when hardware, Windows, files or timer
ownership cannot safely support the launch. Resolve that reported condition
before trying again. Setup cleans up failed writes internally.

FORMATS
MIDI streams from disk and supports sustain, volume, expression, pitch bend
and controller resets. Low bass uses the PC speaker with automatic PSG
fallback. Tandy voices and percussion share the installed sound driver.
VGM reads directly from disk; VGZ expands automatically before playback.
Opening and Checking file show progress. Choose Cancel to stop opening;
Close also cancels safely. Temporary files are created and removed by the
player; no TEMP setting or external decompressor is needed.
Supported VGM/VGZ data preserves the PSG register stream and plays the
initial traversal plus one loop repeat. Plain or expanded files may be up
to 16 MiB, within the supported Tandy PSG command and timing profile.
MOD is arranged for PSG square waves and does not reproduce sample
timbres. Original synthetic examples and corresponding
source are included. Development test records are in TESTS.JSN.
