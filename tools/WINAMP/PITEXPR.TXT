TANDY INSTRUMENTS - SHARED SOUND SETUP

Extract the complete kit to C:\PITEXPR. Exit Windows to DOS and run
C:\PITEXPR\TWSETUP.EXE once. Setup finds your Windows installation and
installs the shared SOUND driver, Winamp and its required files automatically.
Keep this kit in its extracted directory.

Start Windows through your normal display launcher. In Program Manager,
choose File / Run and enter the program you want:
  C:\PITEXPR\MINIPIAN.EXE
  C:\PITEXPR\JOYMIDI.EXE
  C:\PITEXPR\MINIMIDI.EXE
  C:\PITEXPR\BEATS.EXE

Keep MIDIMAP.DRV beside these applications. The same shared sound driver
serves these tools and Winamp; no driver copying or INI editing is needed.
The installed Winamp Setup menu provides Repair and Uninstall.
