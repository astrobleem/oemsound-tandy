# Windows sound source

For ready-to-run downloads, use [the consumer guide](../../README.md) and
[DOS installation instructions](../../docs/INSTALL.MD).

This tree contains the unified [SOUND driver](DRIVER/README.MD), current
player, [Beats Lab](BEATLAB/README.MD), [Fiddle](FIDDLE/README.MD),
[Effects Lab](EFFECTS/README.MD), and the earlier instrument sources.
[The developer guide](../../docs/DEVELOP.MD) maps the current build owners.

The old direct-port PSGPLAY milestone is retained in [PSGPLAY.MD](PSGPLAY.MD).
Its manual test setup is historical and is not the current driver installer.
