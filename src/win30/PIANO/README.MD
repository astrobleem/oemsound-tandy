# Mini Piano

Play Tandy tones with the mouse or PC keyboard. The ready-built app is in
**PITEXPR.ZIP**, alongside Beats, JoyMIDI and MiniMIDI.

[Download](../../../docs/DOWNLOADS.MD) · [Shared setup](../../../docs/INSTALL.MD#add-music-tools)

In Program Manager, run `C:\PITEXPR\MINIPIAN.EXE`. Click and hold a piano
key, or use these physical US keyboard positions:

```text
Key:   A  W  S  E  D  F  T  G  Y  H  U  J  K
Note:  C  C# D  D# E  F  F# G  G# A  A# B  C
```

Use the octave buttons or Left/Right arrows to change register. Release a
held key before playing it in the new octave. Esc or **Panic** releases all
notes. F3 selects the optional PC-speaker support in the current kit.

Three PSG tones can sound at once; extra notes may replace an earlier voice.
These are synthesized chip instruments rather than sampled acoustic piano.

Current matching source is included in the kit. This folder's original 0.1
[source/build notes](LEGACY.MD) are retained with their historical scope.
