# MiniMIDI

A compact MIDI-file player supplied with the instruments in **PITEXPR.ZIP**.
For a playlist, larger-file playback and the current instrument-bank selector,
use [Tandy Winamp](../../../experimental/WINAMP30/README.md).

[Download](../../../docs/DOWNLOADS.MD) · [Shared setup](../../../docs/INSTALL.MD#add-music-tools)

Run `C:\PITEXPR\MINIMIDI.EXE` in Program Manager. Browse to a MIDI file or
type its path, then choose **Play**. Try `C:\WINAMP\STREAM.MID`, installed
with shared Setup. **Stop** or Esc mutes and releases sound.

The current instrument kit includes expressive PSG rendering and optional
PC-speaker support through its PIT control. It uses the shared SOUND driver
and its supplied app-local MIDI support. Keep the extracted kit intact.

Current matching source is inside the kit. The original player's exact
parser limits, earlier mapper and timing results remain in [LEGACY.MD](LEGACY.MD).
