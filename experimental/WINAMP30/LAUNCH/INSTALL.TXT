TANDY WINAMP - CURRENT WINDOWS XT LAUNCHER CANDIDATE
==================================================

Extract TWXT1.ZIP at C:\, producing C:\TWXT1. Keep its runtime files together.
From plain DOS, with Windows completely exited:
  C:\TWXT1\TPLAY C:\WINDOWS /CHECK
  C:\TWXT1\GO
For an existing paired sound installation at another absolute DOS 8.3 path:
  C:\TWXT1\GO C:\W30SND

This local candidate fixes the released UX3 launcher for current XR1 HPXY
and the explicitly reviewed PR155 XRSYNC.DRV candidate.
It includes the matching first-party RESERVE.COM. TPLAY checks that helper,
reserves/reuses the video overlap, installs its owned timer bridge, starts
Windows /R with the player, then removes the bridge on ordinary return.
Use TPLAY directly from DOS; no separate video launcher or chained WINXT
startup is needed. The exact helper reuses its own reservation and allocates
no duplicate. The video reservation remains until reboot, as in XR1.
Stock CGA uses the same command and needs no video reservation.

Prerequisite: Windows 3.0 real mode on a supported Tandy EX/HX, DOS 3.0+,
normal 640 KB, and the paired sound profile. TPLAY verifies the existing
SYSTEM.INI selections and exact installed driver bytes automatically:
  [boot] system.drv=SYSTEM.DRV; sound.drv=TSOUND.DRV; selected display
  SYSTEM\SYSTEM.DRV 2784 bytes, CRC32 3ff05fec
  SYSTEM\TSOUND.DRV 6168 bytes, CRC32 f8517207
The existing isolated PITWIN sound-profile installation supplies TSOUND:
https://github.com/astrobleem/oemsound-tandy/releases/tag/sound-exp-v0.1.0-pit.20261007
This packet supplies no Windows/System driver files or installation changes.

The supported video-memory policy is listed in DEPS\POLICY.MD. Current
Current XRSYNC playback, graphics activity, stop, exit and bridge cleanup
passed with the actual reviewed driver. Earlier HPXY and stock CGA successes
remain recorded for those unchanged paths. The player, audio DLLs, browser and
synthetic songs are unchanged UX3 bytes. TESTS.JSON records the exact run.

Add... selects supported files; Play starts, Stop releases audio. Stop and
close the player, then exit Windows normally. Keep LWFILE.DLL and the other
DLLs beside MINIPLAY.EXE. Preserve the included component notices.
