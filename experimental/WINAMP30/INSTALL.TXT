TANDY WINAMP - INSTALL AND PLAY

DOWNLOAD
https://github.com/astrobleem/oemsound-tandy/releases/download/tandy-winamp-xt1.20261024/TWXT1.ZIP

Use Windows 3.0 real mode, DOS 3.0+ and normal 640 KB on a Tandy 1000 EX/HX.
The sound driver and matching video-memory helper are included. HPXY and
XRSYNC use that helper automatically; stock CGA needs no video reservation.

INSTALL
1. Extract the ZIP's TWXT1 folder to C:\TWXT1. Keep its runtime files together.
2. Exit Windows completely to plain DOS. Copy the sound driver:
     COPY C:\TWXT1\TSOUND.DRV C:\WINDOWS\SYSTEM\TSOUND.DRV
3. In C:\WINDOWS\SYSTEM.INI, change the existing sound.drv line under [boot]:
     sound.drv=TSOUND.DRV
   Keep system.drv=SYSTEM.DRV and your installed display/fonts. Change the
   existing line instead of adding a duplicate. If this installation already
   uses the included TSOUND driver, steps 2-3 are already satisfied.
4. From plain DOS, check:
     C:\TWXT1\TPLAY C:\WINDOWS /CHECK
   After preflight PASS, start:
     C:\TWXT1\GO

Use your actual Windows path if different, in the copy/edit/check steps and
when launching, for example C:\TWXT1\GO C:\W30SND. No separate sound kit or
helper download is needed. No automatic sound installer is supplied.

PLAY
TPLAY reserves or reuses the Tandy video overlap, loads its timer bridge,
starts Windows /R and Winamp, then removes its bridge on normal Windows exit.
Run GO/TPLAY directly from plain DOS; no extra WINXT launcher is needed.
The video reservation remains until reboot and is reused without duplication.
Choose Add... for MID, VGM, VGZ, MOD, TND or SND files. The playlist holds
32 songs; scroll or use Home/End/Page Up/Page Down. Remove changes the list,
not the song file. Stop and close the player, then exit Windows normally.
Use one sound producer at a time; do not run a competing sound/timer TSR.

TROUBLESHOOTING AND UNDO
Keep the runtime DLLs, TBRIDGE.EXE, RESERVE.COM and TPLAY together. If CHECK
refuses, resolve its reported driver, display or ownership problem before
starting. The paired system/sound checks and reservation refusal remain active.
To remove TSOUND, exit Windows and restore the previous sound.drv value in
SYSTEM.INI, normally SOUND.DRV for the stock driver. TSOUND is inactive after
another sound driver is selected. TPLAY itself changes no installation files.

DETAILS
FORMATS.MD describes the supported formats. MOD is a PSG arrangement rather
than sample playback. TESTS.JSON records HPXY/XRSYNC playback, redraw, reservation and cleanup tests. Source, notices and original synthetic examples are included.
