WINDOWS PREREQUISITES / SETUP / ROLLBACK
Existing lawful Windows 3.0 REAL MODE / 640 KB Tandy EX/HX guest, DOSBox-X
machine=tandy and 8086_prefetch, accepted display/reservation launcher.
These drivers are bounded experiments, not full SOUND or multimedia MIDI.
For PIT music Windows kits REQUIRE the included version-1 TSOUND capability.
Merely putting TSOUND beside the app will not replace Windows' SOUND module.
1. Shut down Windows/emulator. Make a NEW disposable copy of the working
   guest; keep the original unchanged. Back up the clone's stock SOUND.DRV
   outside the clone. Resolve the clone's actual SYSTEM.INI sound.drv path.
2. In the CLONE ONLY, copy included TSOUND.DRV to that existing resolved
   Windows SYSTEM\SOUND.DRV path, keeping its internal SOUND identity.
   If the expected setup differs, stop and inspect; no installer is supplied.
3. Keep each app-local MIDIMAP.DRV beside ITS paired clients. Never register
   MIDIMAP globally or copy it over WINDOWS\SYSTEM\MIDIMAP.DRV. In MML3AUTH,
   keep each BEATS/FIDDLE subfolder intact. Preserve accepted display settings.
4. Launch through Program Manager > File > Run. One producer at a time.
   Options DEFAULT OFF: Beats PIT button enables lane five; Mini Piano F3
   selects an extra held pitch; JoyMIDI F3 octave layer needs explicit rearm;
   MiniMIDI PIT button explicitly maps MIDI channel 16. No automatic remap.
   PSGPLAY F3 or /pit; TCHIME /pit; TEXIT /pitpreview only for
   initial listening. Do not use /pitgo until deliberately testing exit.
5. Stop/Escape and normal close mute and release. If abruptly killed and
   ownership sticks, restart the disposable session. For rollback shut down
   and restore stock SOUND.DRV in the clone, or abandon it and use original.
   Do not alter the working guest, startup files or CF defaults.

MML3 AUTHORING
Beats: Grid/MML/PIT buttons; on exports explicit MML3 [P], off retains exact
legacy MML2 output. Copy or NAME.MML Save preserves existing files.
Fiddle: editor/Open/Save and P section; author explicit MML3/[P], V0 or V1.
PIT playback needs explicit opt-in AND paired driver capability, including
empty/all-rest [P]. Missing/busy capabilities refuse, no raw-port fallback.
Limits: MIDI45..96, 8192 source bytes, 32768 tokens, 4096 notes/rests per part,
600 seconds. No PIT envelopes, presets, bends or ties. Original instructions
are in SOURCE/docs/PITAUTH.MD. Apps author MML; movie conversion belongs to
Maker, and this release does not ship media or claim whole-movie integration.

DOS
Use an exclusive plain DOS Tandy session, outside Windows and sound/timer
TSRs. CD PITDOS; run PSGTEST or PSGTEST /pit. Optional PIT adds distinct C5
while PSG triad holds, off before fade. Escape or Ctrl-C stops/releases.
An active speaker or tested Windows DOS-child context refuses before I/O.
This is one cooperative foreground owner, not a system-wide/TSR lock.
Rollback: exit, delete new folder; no installation or startup changes.

LIMITS
PIT2 is a fixed on/off speaker voice, no independent hardware amplitude
control; no simultaneous PIT music and sampled PWM speech. Only ports42/43
and low two port61 bits are used for PIT, preserving immediate upper bits.
PIT0/PIT1, IRQ cadence and interrupt vectors are unchanged. Acquisition needs
quiet speaker; previous unknown PIT mode/divisor is not restored. Windows
beeps/direct writers can bypass cooperative leases and disturb output.
TSOUND is restricted: system beep, envelopes/noise API and SyncAllVoices are
unsupported; Windows system beeps may be silent in this cloned guest.
Cooperative timers can stall; physical EX audio summing/fidelity, hardware
joystick/key input, custom-display UI and full system integration remain open.
TEXIT exit-veto is unqualified. Do not equate DOSBox cycle settings to MHz.
