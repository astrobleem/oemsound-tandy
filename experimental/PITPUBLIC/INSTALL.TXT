WINDOWS INSTALL
You need an existing Windows 3.0 real-mode installation, DOS, 640 KB and
a Tandy 1000 EX/HX. No automatic sound installer is supplied.

1. Extract your selected kit to C:\MML3AUTH or C:\PITEXPR. Exit Windows
   completely to plain DOS.
2. Copy the sound driver (use your actual Windows path if different):
     COPY C:\MML3AUTH\TSOUND.DRV C:\WINDOWS\SYSTEM\TSOUND.DRV
   For the instrument kit, use C:\PITEXPR\TSOUND.DRV instead.
3. In C:\WINDOWS\SYSTEM.INI, set the existing sound.drv line under [boot]:
     sound.drv=TSOUND.DRV
   Keep the TSOUND.DRV filename.
4. Keep each app's paired MIDIMAP.DRV beside its clients. For MML3AUTH,
   extract the complete kit and keep its BEATS/FIDDLE subfolders intact.
   Do not register this app-local mapper as a system MIDI device.
5. Start Windows through your usual required display launcher. Tandy
   graphics still require their video-memory reservation; stock CGA does not.
   In Program Manager, choose File / Run and the desired program, for example
   C:\PITEXPR\MINIPIAN.EXE or C:\MML3AUTH\FIDDLE\MMLFIDL.EXE. Run only one sound producer at a time.

For Winamp, use its own TPLAY launch instructions instead:
https://github.com/astrobleem/oemsound-tandy/blob/main/experimental/WINAMP30/INSTALL.TXT

OPTIONAL PC-SPEAKER VOICE
PIT2 adds an on/off square-wave voice alongside the PSG. It starts off.
Beats: PIT button enables lane five. Mini Piano: F3 adds a held pitch.
JoyMIDI: F3 octave layer needs explicit rearm. MiniMIDI: PIT button maps
MIDI channel 16. PSGPLAY: F3 or /pit. TCHIME: /pit.
Use TEXIT /pitpreview for listening; /pitgo is the explicit exit test.
Stop/Escape and normal close mute and release the sound. If a killed app
leaves ownership busy, restart Windows before using another sound app.

MML3 AUTHORING
Beats exports an explicit MML3 [P] part when PIT is enabled; otherwise it
keeps MML2 output. In Fiddle, author MML3/[P] with V0 or V1. PIT playback
needs opt-in and the paired driver capability. No raw-port fallback exists.
Limits: MIDI 45..96, 8192 source bytes, 32768 tokens, 4096 notes/rests per
part, 600 seconds. No PIT envelopes, presets, bends or ties. The kit includes
original DEFAULT2/PIT.MML examples and SOURCE/docs/PITAUTH.MD details.

DOS
Extract PITDOS, boot plain DOS and change to that folder. Run PSGTEST or
PSGTEST /pit outside Windows and sound/timer TSRs. Escape or Ctrl-C stops
and releases sound. No installation or startup changes are needed.

UNDO AND LIMITS
Exit Windows and restore the previous sound.drv value in SYSTEM.INI,
normally SOUND.DRV for the stock driver. TSOUND is inactive afterward.
TSOUND is a restricted SOUND driver: system beep, envelopes/noise API and
SyncAllVoices are unsupported. PIT2 has no independent volume control and
cannot play alongside sampled speaker speech. Direct Windows beeps/writers
can disturb it. Cooperative timers can stall. Physical EX audio summing,
real joystick/key input and full custom-display integration remain unqualified;
these kit results are emulator tests. Windows 3.1 is not supported.
