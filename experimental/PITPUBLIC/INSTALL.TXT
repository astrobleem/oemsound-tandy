TANDY MUSIC TOOLS - ONE SHARED SOUND INSTALLATION

For Tandy 1000 EX/HX, normal 640 KB, DOS and Windows 3.0 real mode.

Download MML3AUTH.ZIP for Fiddle/Beats authoring, or PITEXPR.ZIP for
Mini Piano, JoyMIDI, MiniMIDI and expressive Beats:
https://github.com/astrobleem/oemdisplay-tandy/releases/download/windows-xt/MML3AUTH.ZIP
https://github.com/astrobleem/oemdisplay-tandy/releases/download/windows-xt/PITEXPR.ZIP

Extract the complete kit, keeping its application folders intact. Exit
Windows to DOS and run the included TWSETUP.EXE. Setup finds Windows and
installs the shared SOUND driver and Winamp automatically. All these
Windows tools use that same installed driver.

Start Windows through your required display launcher, then run the program
from its supplied folder using File/Run in Program Manager or Tandy Start.
Keep the supplied app-local MIDIMAP.DRV files beside their clients; they
are already placed correctly. No system MIDI registration, driver copying
or INI editing is needed.

PIT adds an optional PC-speaker square-wave voice beside the PSG's three
tones and noise. Enable the PIT control in Beats/MiniMIDI, use F3 in Mini
Piano/JoyMIDI, or select MML3/[P] in Fiddle. Stop/Escape and normal close
release sound. Stop one producer before starting another.

C:\WINAMP\GO starts Winamp through its required timer/video launcher.
C:\WINAMP\SETUP offers Launch, Repair and Uninstall Winamp. Shared sound
and Windows XT clients stay installed when Winamp is removed.

DOS PSGTEST is a separate DOS program: extract PITDOS.ZIP, boot plain DOS,
change to that folder, and run PSGTEST or PSGTEST /pit. No Windows sound
installation is needed for the DOS test.
